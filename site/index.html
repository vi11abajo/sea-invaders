01 — The loop

One seed a day, one payout a week

Practice is free. The Daily Run is the ranked one: the same waves for everyone, a ticket in SKR, and the week's best players paid by the program itself.

01

Daily Run

One seed a day. Everyone plays the same board, three attempts per ticket.

02

Best run goes on chain

Server co-signed, written once per player per day. The chain never accepts a score the server did not replay.

03

Weekly pool pays top 10

Monday settlement, straight to the winners' wallets. Empty places roll forward.

04 — Why Seeker, why Solana

The phone is already the wallet

01

SKR is the currency of everything

Tickets, the shop, the Tide's revives. Nothing else to buy or bridge.

02

Sign-In With Solana and Mobile Wallet Adapter

No keys in the app. The wallet signs and sends; the server only co-signs what it replayed.

03

Seeker Genesis Token, verified on chain

One token, one player. It unlocks the SEEKER badge on Home and on both boards.

04

The program pays winners directly

No claim step. Five instructions on chain, nothing else.

Mobile Wallet Adapter · SIWS · Token-2022 extensions · Anchor · deterministic replay core shared by the phone and the server
